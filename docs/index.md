# CCI Withdrawal Form 1.0.0

Use CCI Withdrawal Form when customers should be able to send a withdrawal statement online. It works for signed-in customers and guests. Every confirmed request creates an immutable statement record; compatible requests also create a normal PrestaShop merchandise return.

## Set up the form

1. Install `cci_withdrawal-1.0.0.zip` in **Modules > Module Manager**.
2. Open **Cool Cat Ideas > CCI Withdrawal Form**.
3. Review buyer types, guest access, product exclusions and automatic access points.
4. Decide whether confirmation PDFs and the post-order access email should be enabled.
5. Optionally enable merchandise returns and set their technical period in **Shop Parameters > Order Settings**.
6. Submit a test request and open it in **Cool Cat Ideas > CCI Withdrawal Form > Submitted withdrawals**.

The form can cover all products in an order or selected items and quantities. It does not decide whether a customer has a legal right to withdraw, and it does not issue a refund automatically.

The module works without a license key and supports PrestaShop 9.0.0-9.1.5.

# Support

Include the following when reporting an issue:

- module, PrestaShop and PHP versions;
- active shop, language and theme;
- whether the order belongs to a customer or guest;
- order state and configured merchandise-return period;
- enabled buyer types and exclusion settings;
- exact reproduction steps and the visible error;
- relevant PrestaShop logs with personal data removed.

Do not send production credentials, full database dumps, email contents or
customer identity documents through an ordinary support channel. Use a staging
copy and temporary least-privilege access when secure access is necessary.

The Free module is supplied without a license key. Legal classification of a
specific purchase, custom theme work and store-process consulting are separate
services rather than defects in the module package.
